4. **Receipt = GRN (SF-4/SF-5):** receipt page (MES redirects to it, no popup). 6. **WIP a slip can send:** previous op's good qty − already sent.
7. **Cost:** outsourced ops cost ₹0 in routing/BOM, shown as "charged on vendor bill".
8. **Remove orphan columns/code:** routing + order ops `material_supply_type`, `subcontract_input_type`, `subcontract_cost_per_unit`, `subcontract_service_product_id`, `subcontract_lead_time_days`, `dispatch_buffer_days`, `return_buffer_days` (→ 3 hour columns); `production_routing_operation_materials.supplied_by`; subcontract-only Purchase additions from the rework (PR/PO operation links, subcontract PR→PO path, GRN-screen subcontract guards) once nothing reads them; `ProcessSubcontractReceiptOnGrnApproved` (PO path gone).
